# Palestra

App web installabile per iPhone. Non richiede account né backend: scheda, spunte e appunti vengono salvati nel browser del dispositivo.

## Installazione su iPhone

Per aggiungerla alla schermata Home, l’app deve essere pubblicata su un indirizzo HTTPS. Il modo più semplice è caricare **tutti i file contenuti in questa cartella** su un hosting statico gratuito, per esempio GitHub Pages o Netlify Drop. Non occorre configurare un database o un server applicativo. Una volta pubblicata:

1. Apri l’indirizzo dell’app in **Safari** su iPhone.
2. Tocca **Condividi** e poi **Aggiungi alla schermata Home**.
3. Conferma con **Aggiungi**. Da quel momento apri Palestra dalla sua icona.

La prima apertura deve avvenire online; in seguito l’interfaccia è disponibile anche offline. I dati restano nel browser installato su quel dispositivo e non si sincronizzano con altri dispositivi. Evita di cancellare i dati di Safari per conservare appunti e scheda. L’app non include pubblicità, login o chiamate a servizi esterni.

## Uso

- **Scheda:** seleziona Giorno 1–4; usa **Aggiungi esercizio** per inserire un nome. Le frecce spostano l’esercizio, la matita lo rinomina e × lo elimina. La casella segna il completamento; **Reset sessione** azzera le spunte del giorno.
- **Appunti:** scrivi in Setup macchinari o Progressioni. Il testo viene salvato mentre digiti.

La scheda iniziale è vuota, pronta da compilare.
